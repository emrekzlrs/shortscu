# Shortscu

Metnini yapıştır, sesini ekle; YouTube Shorts videosunu kelimelere göre kendisi kurar.

**İndir:** [Shortscu-Windows-2.2.0.zip](https://github.com/emrekzlrs/shortscu/releases/latest) (Windows 10/11, 64 bit)

Zip'i bir klasöre çıkar, `Shortscu.exe`'yi çalıştır. Program açılışta yeni sürüm var mı diye bakar ve tek tıkla günceller.
